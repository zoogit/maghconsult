# WordPress CMS Plan

This site can start as a static frontend and later pull these content areas from
WordPress through the REST API or GraphQL.

## Pages

- Homepage / landing page
- Who We Are
- What We Offer
- Useful Links
- Events
- Blog

## Recommended Content Types

### Services

- Title
- Short summary
- Full description
- Display order
- Optional icon or image

### Useful Links

- Title
- URL
- Description
- Category
- Display order

### Events

- Title
- Event date
- Time
- Location or online link
- Short description
- Registration URL
- Status: upcoming or past

### Blog Posts

- Title
- Excerpt
- Body content
- Featured image
- Category
- Publish date

### Site Settings

- Firm name
- Tagline
- Contact email
- Phone number
- LinkedIn URL
- Booking URL
- Founder name
- Founder photo
- Footer text

## First Build Approach

1. Use placeholder content in the static frontend.
2. Recover or rewrite real page copy.
3. Set up WordPress fields with ACF or native custom post types.
4. Connect the frontend to WordPress once the content model is stable.
